## Notes for the tester run

- **Setting up a gated contest:** in the admin console (Contest Manager →
  create/edit), use the **Entry Requirements** section to set a Minimum XP
  and/or check the lessons that must be passed. Leave both blank for an open
  contest.
- **The gate is client-side for now.** XP and lesson completion live on the
  device, so the lock reflects *this* device's progress. It's a motivational
  gate, not anti-cheat; the rule itself is stored on the server so enforcement
  can move server-side later with no app change.
- **Trim before publishing:** if a previous TestFlight build already shipped
  the `$`-prize (#18) or tab-fit (#20) fixes to testers, drop those two
  sections from the paste block so testers only see what's genuinely new in
  this build.
